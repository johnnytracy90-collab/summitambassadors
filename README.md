# Summit Ambassador Hub: flat website package

This version has **no folders**. Every file sits next to `index.html`, so it uploads to GitHub in one step with nothing to get lost.

## Upload it to GitHub

1. Unzip this package. Open the folder. You will see 18 files and no subfolders.
2. In your GitHub repository, select **Add file, then Upload files**.
3. Press Ctrl+A (Cmd+A on a Mac) inside the folder to select **all 18 files**, then drag them into the browser window. Wait for every file to finish uploading. The PowerPoint is 14 MB and takes the longest.
4. Select **Commit changes**.
5. Wait a minute or two, then reload your site with Ctrl+Shift+R (Cmd+Shift+R on a Mac).

If you already uploaded the earlier package, these files will simply replace the old ones with the same names. You can delete any leftover `assets` or `docs` folders from the repository afterward.

## Check that it worked

Your repository's main page should list `index.html`, `README.md`, `robots.txt`, eight `.png` images, and seven documents (six `.pdf` files and one `.pptx` file). The page images should appear.

## The same advice still applies

- **The site is public.** On GitHub's free plan, anyone with the link can open it, including the "For ambassadors" documents and the contact details on the page. The page asks search engines not to list it, but that is a request, not security.
- **Get approval** from your web or marketing team for the logos, the documents, and the forms (which collect names, phone numbers, and Scouting IDs).
- **Replace or remove** the bracketed "More coming soon" card in the Library.
- **Confirm** that the email address, phone number, and address on the page are the ones you want public.
- **Two items in the source documents:** the checklist footer's "25*46" typo, and the age mismatch (thirteen versus fourteen) between the elevator pitch and the orientation.

## How the forms work

Each form checks the required fields, shows a review screen, and offers an **Open email** button that creates a message to Johnny.Tracy@scouting.org. The person still presses Send in their email app. A **Copy message** button is there as a backup. A form tool such as Microsoft Forms or Google Forms can collect responses automatically; ask your web team about connecting one.

## Updating later

- **Replace a document:** upload the new version with the **same file name**.
- **Edit text:** open `index.html` in the repository, select the pencil icon, edit, and commit.
